Zero Themes on GitHub Pages

Welcome to the official developer documentation for Zero Themes. Our templates are designed from the ground up to eliminate the common pitfalls of hosting static websites on GitHub Pages, specifically supporting repository project subpaths (e.g. https://username.github.io/website_name/) without broken stylesheet links, broken image assets, or 404 routing errors.

Key Benefit: Zero build step required! You don't need Node.js, Ruby, or complex Docker containers to launch your website. Push pure HTML, CSS, and JS directly to GitHub.

GitHub Pages Deployment (60 Seconds)

Deploying your purchased theme to GitHub Pages takes less than a minute. Follow these three simple steps:

Step 1: Create a GitHub Repository

Log in to your GitHub account and create a new repository (e.g. my-premium-website). You can make it Public or Private (Private repositories also support GitHub Pages on GitHub Pro/Enterprise plans, while Public repositories support GitHub Pages on free accounts).

Step 2: Upload or Push Your Theme Files

Clone the repository to your local computer and extract your Zero Theme files into the root folder:

# Initialize your local git folder
cd "D:/Premium Web"
git init
git add .
git commit -m "Launch Zero Themes on GitHub Pages"
git branch -M main
git remote add origin https://github.com/your-username/your-repository-name.git
git push -u origin main

Step 3: Enable GitHub Pages

In your GitHub repository web interface:

  1. Go to Settings > Pages.
  2. Under Build and deployment, set Source to Deploy from a branch.
  3. Under Branch, select main and folder / (root), then click Save.
  4. Within 30–60 seconds, your site will be live at https://<username>.github.io/<repository-name>/!

Subfolder Path & BaseURL Safety

The most frequent reason websites fail on GitHub Pages is the use of absolute root paths (such as /assets/css/style.css). When a project site is deployed at username.github.io/website_name/, an absolute path looks at username.github.io/assets/..., resulting in a 404 error and unstyled pages.

Important Rule: Zero Themes uses relative paths (./assets/css/style.css) throughout all templates. This ensures that your pages load cleanly whether viewed locally on disk, under a GitHub repository subfolder, or on a root custom domain!

Custom Domain & Free SSL Certificate

If you want to use your own domain (e.g. https://www.yourdomain.com) instead of username.github.io:

  1. In your repository root, create a file named CNAME (all caps, no file extension).
  2. In the file, write your domain name: www.yourbrand.com.
  3. In your DNS provider (Cloudflare, Namecheap, GoDaddy), point your CNAME record for www to username.github.io.
  4. In GitHub Pages Settings, check Enforce HTTPS to obtain a free Let's Encrypt SSL certificate automatically!

Customizing Dark & Light Mode

All color tokens are cleanly declared as CSS variables in assets/css/style.css. You can easily modify brand colors or default shades: 

/* Customize your brand color in assets/css/style.css */
:root {
  --primary: #4f46e5;       /* Your primary brand accent */
  --accent: #06b6d4;        /* Secondary gradient accent */
  --bg-main: #f8fafc;       /* Light mode background */
  --text-main: #0f172a;     /* Light mode text */
}

[data-theme="dark"] {
  --bg-main: #090d16;       /* Dark mode obsidian background */
  --text-main: #f8fafc;     /* Dark mode text */
  --primary: #6366f1;       /* Vibrant dark accent */
}

The state is automatically persisted in localStorage.getItem('zero_theme') so user preferences are remembered on return visits.

Google AdSense & Ads Integration

Zero Themes are designed to be 100% ad-friendly and compliant with Google AdSense, Carbon Ads, and EthAds policies.

To enable AdSense across all pages:

  1. Sign in to your Google AdSense account and copy your publisher code.
  2. Paste the Google script tag into the <head> section of your HTML files:
<!-- Google AdSense Header Script -->
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX"
     crossorigin="anonymous"></script>

Then replace the contents inside any <div class="ad-container"> element with your responsive AdSense display ad unit: 

<!-- Example AdSense Display Unit -->
<div class="ad-container">
  <ins class="adsbygoogle"
       style="display:block"
       data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
       data-ad-slot="1234567890"
       data-ad-format="auto"
       data-full-width-responsive="true"></ins>
  <script>
       (adsbygoogle = window.adsbygoogle || []).push({});
  </script>
</div>

Search Engine Optimization (SEO)

Every page is pre-structured with Semantic HTML5 (header, nav, main, article, footer) and search-engine metadata:

  • Canonical URLs: Prevents duplicate content penalties when hosted on both custom domains and GitHub Pages subdomains.
  • OpenGraph & Twitter Cards: Rich previews with full-bleed cards when shared on Slack, Twitter/X, Discord, and LinkedIn.
  • XML Sitemap: Pre-generated sitemap.xml with clean frequency and priority attributes.
  • Robots.txt: Allows all major search engine crawlers with direct pointer to the sitemap.

Frequently Asked Questions

Can I run a contact form on a static GitHub Pages site?

Yes! Zero Themes supports form endpoints like Formspree, Formkeep, or Web3Forms with zero server backend. Simply replace the form action attribute with your endpoint URL.

Do I need to pay GitHub for hosting?

No. GitHub Pages is completely free for standard public static sites with up to 100 GB/month bandwidth and 1 GB repository storage.

Why does the hamburger menu open from the left?

By design, the quick trigger button is easily reachable on the right side of the navigation bar, while the navigation drawer slides out ergonomically from the left side to provide maximum viewing breadth for links and widgets.
